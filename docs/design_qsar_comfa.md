## 0. 한 문장

현재 파이프라인은 이미 QSAR이다 — 서열 기술자로 활성을 예측한다. 빠진 것은
**CoMFA가 제공하는 3차원 장(field) 기술자**이고, 이 프로젝트는 그것을 넣기 위한
전제조건을 **이미 전부 갖추고 있다.** 그래서 추가 도킹 비용 없이 두 가지를 동시에
얻을 수 있다 — 조성 포화의 돌파 시도, 그리고 **설계 지침을 주는 등고선 지도.**

---

## 1. 현재 모델이 QSAR의 어디에 있는가

| QSAR 개념 | 이 프로젝트의 대응물 |
|---|---|
| 활성 (activity) | `score = −ad_med_ds`, AutoDock 50런 중앙값 |
| 기술자 (descriptor) | ESM-1b 층 2 mean-pool 1280차원 / 아미노산 조성 24차원 |
| 회귀 | RandomForest (SeekRank 기본) |
| 검증 | 클러스터 단위 분할 + `rho_xval` |
| 적용 범위 (AD) | **없음** ← 후보 1,500개를 채점할 예정인데 빠져 있다 |
| 해석 | **없음** ← RF는 "어디를 어떻게 바꿔라"를 말해주지 못한다 |

즉 **2D QSAR까지 와 있고 3D QSAR이 없다.** 그리고 2D 쪽에서는 이미 천장을 쳤다.

### 1.1 조성 포화 — 왜 새 기술자 계열이 필요한가

측정된 사실(methods §13.2)이 이 작업의 출발점이다.

| 특징 | 차원 | `rho_xval` (학습 157, 5-fold × 2) |
|---|---|---|
| 아미노산 조성 | 24 | 0.4218 ± 0.1471 |
| ESM-1b 층 2 | 1280 | 0.4438 ± 0.1383 |
| ESM-1b 층 33 | 1280 | 0.3765 ± 0.0877 |

ESM 최고 층의 이득은 **+0.022, 오차막대의 6분의 1**이다. 층 0은 조성의 선형변환인데
평가셋 최고였다. 결론은 이미 문서에 적혀 있다 — **예측 가능한 부분이 조성 수준에서
포화된다.**

그런데 그 포화를 만든 지배 요인 목록을 보면 돌파 방향이 그 안에 적혀 있다.

| 지배 요인 | 성격 | 조성이 담는가 | 3D 장이 담는가 |
|---|---|---|---|
| 전하 (EV 2가 양이온) | 조성적 | 전체 순전하만 | **결합부위의 국소 전하 분포** |
| 부피 (포켓 수용) | 조성적 | 전체 부피 비율만 | **포켓 어디가 좁은지** |
| 방향족 (바이피리디늄 스태킹) | 조성적 | 전체 방향족 비율만 | **고리가 스태킹 거리에 있는지** |

세 요인 모두 **"얼마나 많은가"는 조성이 담지만 "어디에 있는가"는 담지 못한다.**
도킹 점수는 결합부위에서 결정되는데 조성은 633잔기 전체의 평균이다.
`cband`가 라벨과 거의 무관하다는 발견(ρ = −0.14)도 같은 방향을 가리킨다 —
모델이 배우는 것은 계통적 유사도가 아니라 **국소적 무언가**다.

**3D 장은 바로 그 "어디에"를 기술한다.** 조성을 못 이기면 그것도 결과다
(「이 라벨에서 공간 정보는 추가 기여가 없다」는 더 강한 포화 주장이 된다).

## 2. 왜 이 프로젝트에서는 CoMFA가 실제로 성립하는가

CoMFA는 보통 **정렬(alignment)에서 죽는다.** 이 프로젝트는 그 문제가 이미 해결돼 있다.

| CoMFA의 통상 난점 | 이 프로젝트의 상태 |
|---|---|
| 활성 형태(conformer)를 모른다 | AF2 구조 321개 확보, pLDDT 평균 95.5 |
| 3차원 중첩 기준이 없다 | **321개 전부 1SU6 좌표계에 중첩됨.** 6OND도 먼저 1SU6로 옮김 |
| 결합부위 정의가 모호 | **F41 등가 CA, 반변 15 Å 박스가 이미 확정** (`f41_pos` 컬럼) |
| 격자 파라미터를 임의로 고름 | **npts 80 × 0.375 이 이미 검증됨** (반변 18에서 상관 붕괴) |
| 활성값이 불균질 | 전부 같은 엔진·같은 조건·50런 중앙값 |
| 동종 계열이어야 함 | IPR010047 한 패밀리, 아키텍처별 참조 이량체까지 맞춤 |

**정렬·격자·부위가 모두 도킹 때문에 이미 고정되어 있다.** CoMFA를 하기에 이보다
좋은 조건은 드물다. 추가로 필요한 계산은 **없다** — 구조는 있고, 장은 그 구조에서
직접 계산된다.

### 2.1 좌표계 선택은 사전 등록 사항이다

장을 어느 원점에 걸 것인가가 결과를 바꾼다. 두 선택지를 다 구현했고 주 분석을
**라벨을 보기 전에** 고정했다.

| 모드 | 원점 | 역할 |
|---|---|---|
| **`SELF`** | 각 구조 자신의 F41 등가 CA | **주 분석.** 도킹 박스 규칙과 동일 → 점수가 나온 바로 그 부피를 기술 |
| `REF` | 1SU6 PHE41 CA (전 구조 공통) | 민감도 분석. CoMFA 정통이지만 `center_dev` 9.69 Å 구조는 포켓이 격자 밖으로 밀림 |

`SELF`를 주 분석으로 둔 이유는 단순하다 — **라벨이 그 박스에서 나왔다.**
`center_dev`는 그대로 공변량으로 남아 축 이동량을 담는다.

> 성능을 보고 둘 중에 고르는 것은 **ESM 층을 평가셋으로 고르는 것과 같은 오류**다.
> 이 프로젝트는 그 부풀림을 실측해 뒀다 — 순수 잡음에서 n=55·34층이면 ρ 0.283.

### 2.2 CoMFA 대신 CoMSIA를 주력으로 둔 이유

세 가지이고, 세 번째가 이 프로젝트에 특히 중요하다.

1. **특이점이 없어 cutoff가 불필요.** Lennard-Jones 1/r¹²는 단백질 내부에서 발산해
   ±30 kcal/mol로 잘라야 한다. 그러면 매몰된 모든 격자점이 같은 상수를 공유하고
   장이 불연속이 된다. 가우시안은 어디서나 유한하다.
2. **autogrid 의존성이 없다.** 조립 PDB에서 바로 계산되므로 수용체 준비·격자 생성
   없이 **어떤 후보든 채점 가능**하다. 이것이 "적용가능한 모델"의 핵심이다.
3. **장을 여섯 개 쓸 수 있다.** 입체·정전기에 **소수성·수소결합 공여체/수용체·방향족**을
   더한다. EV가 2가 바이피리디늄 양이온이므로 **방향족 장은 장식이 아니라 화학이다.**

고전 CoMFA 장(LJ + Coulomb)도 **프로젝트 자신의 autogrid 맵에서 읽어** 함께 쓴다
(`fields_autogrid.py`). 그쪽이 라벨을 만든 물리와 동일하므로, 둘을 나란히 두는 것이
선호가 아니라 **공정한 비교**가 된다.

## 3. 이 접근이 해결하는 기존 미결 과제

### 3.1 변이체 288개 — 표본을 고르는 대신 특징을 고친다

문서가 진단을 이미 내려 놨다(methods §5): 문제는 표본이 아니라 **표현**이다.
mean-pool ESM은 633잔기 중 1개가 바뀌어도 1280차원 벡터가 거의 안 움직여서
288개가 한 좌표에 뭉친다. 그리고 라벨로 변이체를 골라 넣는 것은
**informative censoring**이라 금지돼 있다.

**3D 장은 점돌연변이에 민감하다.** F41 자리에서 PHE → ILE 하나만 바뀌어도
그 위치의 방향족 장과 입체 장이 직접 달라진다. S3 설계가 겨냥한 바로 그 목표를
수작업 기술자 64차원이 아니라 장 자체가 달성한다.

> **단, 전제가 있다.** 장은 실제 곁사슬 좌표를 읽는다. 288개 변이체의 장을 만들려면
> 각 서열을 백본에 **쓰레딩**해야 한다 (식별자만 바꾸면 안 된다 — `apply_point_mutation`에
> 명시해 뒀다). 쓰레딩 전까지 변이체 트랙은 `site`/`shell` 기술자로 간다.

### 3.2 적용 범위 — 후보 채점을 방어 가능하게 만든다

풀 A(IPR010047 잔여 ~1,400) · 풀 B(ColabFoldDB) · 풀 C(de novo)를 채점할 예정인데,
**풀 C는 구조적으로 학습 분포 밖이다.** AD 없이 순위를 내면 그 목록은 장식이다.

세 가지 측도를 함께 쓴다. 서로 다른 실패를 잡기 때문이다.

| 측도 | 공간 | 무엇을 잡는가 |
|---|---|---|
| leverage `h` | PLS 잠재 | 모델이 쓰는 방향으로 멀리 간 점 |
| kNN 거리 | PLS 잠재 | 학습 점들이 없는 빈 구역 |
| **DModX** | X 잔차 | **모델의 X 평면이 아예 설명하지 못하는 구조** |

세 번째가 없으면 안 된다는 것을 테스트가 실제로 보여줬다 —
밀도가 두 배인 엉뚱한 구조가 잠재공간에서는 중앙에 떨어져 `knn_ratio` 0.48로
**"범위 내"로 읽혔다.** 잠재공간은 모델이 쓰는 방향만 보기 때문이다.
de novo 설계는 전형적으로 DModX에서 걸린다.

### 3.3 등고선 — 순위 모델을 설계 지침으로 바꾼다

RF는 "이 상동체 점수 5.2"까지만 말한다. PLS 계수는 격자점에 살아 있으므로
**공간에 되돌려 볼 수 있다.**

```
파란 등고선  이 자리에 이 성질이 많으면 → EV 결합이 강해진다
빨간 등고선  이 자리에 이 성질이 많으면 → 약해진다
```

이것이 **변이체 트랙과 생성 트랙에 직접 먹이는 입력**이다. 다음에 어느 위치에 어떤
치환을 넣을지를 모델이 지목한다. 그려지는 값은 계수 자체가 아니라
**계수 × 그 격자점의 표준편차**(통상의 `StDev*Coeff`)다 — 변하지 않는 격자점은
계수가 커도 의미가 없으므로.

## 4. 생성 모델로의 확장 (요청사항)

예측기를 **oracle로 떼어 쓸 수 있게** 설계했다.

```
     ┌─ LigandMPNN / ESM3 ─→ 서열 후보
     │
     ↓
  구조 예측 (AF2/ColabFold) ─→ 이량체 조립 (기존 코드) ─→ 조립본 PDB
     │
     ↓
  compute_fields()  ──→  CoMFAModel.predict()  ──→ 예측 score
     │                          │
     │                          └→ AD 3종 게이트 (leverage · kNN · DModX)
     ↓
  상위 N개만 실제 도킹으로 확인  ──→ 라벨 추가 ──→ 재학습 (닫힌 고리)
```

이를 위해 인터페이스를 분리해 뒀다.

| 요소 | 왜 생성 트랙에 필요한가 |
|---|---|
| `compute_fields(structure, grid, center)` | 구조만 있으면 채점 가능. 도킹 준비 체인 불필요 |
| `CoMFAModel.predict(X)` | 동결 저장·재적용 가능. 필터·스케일러가 모델에 같이 들어 있음 |
| `fit_domain` + `x_residual_distance` | **de novo 후보는 분포 밖이 기본값.** 게이트 없이는 순위가 무의미 |
| 등고선 (`contours.py`) | 무작위 생성이 아니라 **지목된 자리를 겨냥한 생성** |
| `km_bridge.calibrate_km` | 생성 후보를 kcal/mol이 아니라 **Km 눈금**으로 보고 |

등고선이 생성 트랙에 주는 것이 특히 크다. 서열 공간을 무작위로 뒤지는 대신
**"이 자리에 음전하, 저 자리에 방향족"** 이라는 제약으로 LigandMPNN을 몰 수 있다.

## 5. Km 쪽 — 무엇을 주장할 수 있고 무엇을 못 하는가

사슬은 두 구간이고 **학습되는 것은 앞 구간뿐이다.**

```
서열/구조 ──(field QSAR, n=157 학습)──→ 예측 도킹 점수
예측 도킹 점수 ──(검증된 프록시, n=19)──→ Km
```

**n=19로는 Km 회귀기를 학습할 수 없다.** 할 수 있는 것은 두 가지다.

1. 도킹 점수가 Km을 따라가는지 **확인** — 보고된 ρ는 `ad_med` +0.913
2. 예측 점수를 Km 눈금에 **보정(calibration)** — 구간을 넓게 열어서

그리고 문서가 기록해 둔 함정 두 개를 코드에서 강제했다.

| 함정 | 처리 |
|---|---|
| **집단 혼합 ρ 부풀림** (전체 +0.730 → 부분군 −0.539로 역전된 선례) | `validate_proxy`가 집단별 ρ를 항상 분리 보고. pooled는 참고용으로 표시 |
| **`dchg` 교락** — 전하 변화가 단독으로 점수와 상관 | `partial_spearman`으로 dchg 편상관. 방어 가능한 숫자는 **dchg-잔차 ρ +0.600 (p=0.0066)**, 원시 +0.913이 아니다 |
| 보정 범위 밖 외삽 | `extrapolating()`이 플래그. n=19의 점수 범위를 벗어난 예측은 표시됨 |

Km은 로그 스케일로 보정한다(오차가 승법적이므로). R²가 아니라 **LOO MAE**를 보고한다 —
n=19에서 R²를 내면 독자가 이것을 학습된 예측기로 읽게 되고, 그건 사실이 아니다.

## 6. 보고 규칙 — 코드가 강제하는 것

문서에 적힌 금지사항을 주석이 아니라 **코드 경로**로 옮겼다.

| 규칙 | 어디서 강제되나 |
|---|---|
| 라벨 부호 (`score = −ad_med_ds`) | `labels.assert_score_sign` — 반전 누락과 이중 반전을 둘 다 잡음 |
| 노이즈 바닥 미만은 주장 불가 | `labels.resolvable` · `evaluate.noise_floor_from_pairs` |
| 분할 단위는 클러스터 | `splits.*` 전부 GroupKFold. 내부 선택 루프까지 |
| 확장분은 평가셋 금지 | `splits.split_from_targets`가 AssertionError |
| 필터·스케일러는 학습 행에서만 fit | `CoMFAModel.cross_validate`가 fold마다 재적합 |
| `cband`는 잔차화 금지 | `evaluate.TECH_COVARIATES`에서 의도적으로 제외 |
| `cband` 계수는 RMSD·center_dev 보정 후에만 | `covariate_regression`이 둘 없으면 KeyError |
| 양 끝 구간 개별 보고 금지 | `report_by_band`가 `≥60`(2개)·`<30`(3개)를 합침 |
| y-randomization 필수 | `CoMFAModel.y_randomization` |
| 재현성 | 시드 `20260916` 고정. `n_jobs` 비결정성은 §13.6대로 문서화만 |
| `X` 잔기 삭제 금지 | `composition`이 길이에는 세고 bin에는 안 넣음 |
| FASTA 헤더는 라벨이 아니다 | `read_fasta` docstring + 라벨은 항상 `dock_scores.tsv`에서 조인 |

## 8. 예상되는 결과와 그 해석

**어느 쪽이 나와도 보고할 내용이 있다.** 이것이 설계의 요점이다.

| 결과 | 해석 |
|---|---|
| 장 > 조성, 차이가 claimable | **공간 정보가 기여한다.** 등고선이 설계 지침으로서 가치를 가짐 |
| 장 ≈ 조성 (n=55에서 구별 불가) | 조성 포화가 **공간 수준에서도 확인됨.** §13의 주장이 강해진다. 등고선은 여전히 해석 도구 |
| 장 < 조성 | 격자가 잡는 변동이 라벨과 무관. 조립 인공물 쪽을 먼저 의심 (잔차화 라벨로 재확인) |
| `rho_xval` ≤ y-randomization 최대 | **선택 편향이다.** 성분 수 선택이 산 것이므로 보고하지 않음 |
| AD 밖 후보가 다수 | 후보풀이 학습 분포와 다름. 도킹으로 확인할 N을 늘려야 함 |

n=55에서 claimable하지 않은 차이는 **결과가 아니다.** `evaluate.claimable`이
Fisher-z로 그것을 명시적으로 판정하고, 코드가 그렇게 출력한다.

## 9. 한계 — 논문에 명시할 것

1. **Fe-S 클러스터 부재.** FES가 F41 CA에서 5.13 Å인데 `receptor_types`에 금속이 없다.
   정전기장이 불완전하다. 장 모델에서는 이 결손이 **격자점 수준으로 드러나므로**
   오히려 2D 기술자보다 영향이 직접적일 수 있다. Cys를 중성으로 둔 것도 같은 이유
   (`pdbio.FORMAL_CHARGE` 주석에 근거 기재).
2. **전하 모델이 coarse하다.** 기본값은 pH 8 형식전하다. 정확한 장은 프로젝트의
   기존 pdb2pqr/PROPKA pH 8 출력을 `charges_from_pqr`로 넣어야 한다.
   지배 요인이 전하·부피·방향족이라는 측정 결과가 coarse 모델의 1차 근사를 정당화하지만,
   **주 결과는 PQR 전하로 재확인해야 한다.**
3. **조립 품질이 `cband`와 교락.** 유사도가 낮을수록 RMSD 0.61 → 2.51.
   장은 구조에서 직접 나오므로 **2D 기술자보다 이 인공물에 더 민감하다.**
   잔차화 라벨 민감도 분석이 선택이 아니라 필수다.
4. **변이체 장에는 쓰레딩이 필요하다.** 식별자 치환으로는 장을 만들 수 없다.
5. **단일 형태.** AF2 모델 하나씩이므로 형태 유연성이 없다. CoMFA의 고전적 한계.
6. **n=157.** 격자 기술자 59,058개에 대해 작다. PLS와 성분 수 제한이 그래서 필요하고,
   y-randomization이 그래서 필수다.
