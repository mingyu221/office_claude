# 1부. Ni 배위 등급 A/B/C/D — 가장 많이 물어보신 것

**CELL 28a-8b** 에서 만든다. 결과는 `result/table/ni_site_grade.csv`.

## 1-1. 무엇을 재는가

Boltz 가 ChCODH2(사슬 A) + 후보 단백질(사슬 B) + **Ni 이온** 을 함께 접은 구조에서,
**Ni 주변에 어떤 원자가 모여 있는지**를 센다.

## 1-2. 계산 순서

```
1. 예측 구조에서 NI 원자 좌표를 찾는다
2. 그 좌표에서 2.6 Å 안에 있는 원자를 모은다
      ※ 사슬 B(후보 단백질) 의 원자만 센다. 사슬 A(ChCODH2) 는 제외
      ※ 골격 원자(N, O, C, CA, CB)는 제외 — 단 ASP/GLU/HIS/CYS 는 예외로 인정
3. 한 잔기가 원자 2개로 붙어도 1개로 센다 (잔기 단위 중복 제거)
4. 모인 잔기를 종류별로 센다 → ncys, nhis, nacid
5. 아래 규칙으로 등급
```

## 1-3. 등급 규칙 (코드 그대로)

| 등급 | 조건 | 붙인 이름 | 뜻 |
|---|---|---|---|
| **A** | `ncys >= 4` | Cys4 | 티올레이트 4개. **Ni(II) 같은 연한 금속의 전달·저장형 자리** |
| **B** | `ncys == 3` | Cys3 + 보조 | 구조적 금속 자리 |
| **B** | `ncys == 2` **and** `nhis >= 1` | Cys2His | 구조적 금속 자리 |
| **C** | `ncys >= 1` **or** `nhis >= 3` | His 중심 | 촉매 금속 자리 가능성 |
| **D** | 그 외 | 산소 공여체 위주 | **표면에 스친 것으로 의심** |

즉 **Cys 개수가 사실상 전부**다. 이름이 A/B/C/D 라 정교해 보이지만
실제로는 `Ni 주변 2.6 Å 안의 Cys 잔기 수`를 4 / 3 / 2 / 그 외로 자른 것이다.

## 1-4. 왜 Cys 개수인가 (이 부분은 화학이다)

HSAB — Ni(II) 는 **연한(soft) 금속**이고 Cys 의 티올레이트 S⁻ 는 **연한 염기**다.
Asp/Glu 의 카복실산 O 는 **단단한(hard) 염기**라 Mg²⁺·Ca²⁺ 쪽이다.
**금속을 잡았다 놓는 운반 단백질**은 티올레이트를 쓴다 — HypA, CooC, 메탈로티오네인,
아연 손가락이 전부 그렇다. 그래서 Cys4 를 최상으로 뒀다.

D 가 "표면 부착 의심" 인 이유도 같다. Ni 옆에 O 만 있으면 그건 배위가 아니라
**그냥 그 자리에 놓인 것**일 가능성이 높다.

## 1-5. 임의로 정한 두 값

| 상수 | 값 | 출처 | 바꾸면 |
|---|---|---|---|
| `TIGHT` | **2.6 Å** | 화학 + **내가 정함** | Ni–S 2.2 Å, Ni–N 2.1 Å 이 실측 범위. 2.6 은 거기에 여유 0.4 Å. **3.0 으로 늘리면 D 가 C 로 올라오기 시작한다** |
| `CUT_NI` | **3.5 Å** | **내가 정함** | 이건 등급이 아니라 **"Ni 이 어디엔가 놓이긴 했나"** 의 문턱. 411 구조 전부 통과했다 |

**주의:** `CUT_NI 3.5` 와 `TIGHT 2.6` 은 다른 것이다. 보고서에서 "Ni 있음 411" 은 3.5 기준,
"배위 grade" 는 2.6 기준이다.

## 1-6. 이 등급의 한계 — 발표에서 나올 질문

1. **예측 구조다.** 결정구조가 아니다. Boltz 가 Ni 을 어디에 놓을지 정했다
2. **후보 단백질 쪽만 본다.** ChCODH2 와 함께 만드는 자리는 안 센다
3. **재현성은 확인했다** — 직교체끼리 좌표가 Δ **0.01–0.08 Å** 로 일치했다.
   이게 이 축을 믿는 유일한 근거다 (ipTM 은 이 검사를 통과 못 했다)
4. **A 가 4개뿐**이고 그중 2개(HslO·그 Y19 직교체)는 세 균주 공통이다

# 5부. 열 이름 사전

출력에 찍히는 열이 각각 무엇인지. 도구가 준 것과 제가 만든 것을 구분했다.

## 5-1. Foldseek `.m8` (도구가 주는 것)

`--format-output "query,target,fident,alnlen,qcov,tcov,evalue,bits,prob,alntmscore,lddt"`

| 열 | 뜻 | 읽는 법 |
|---|---|---|
| `query` / `target` | 질의 / 대상 구조 파일 | |
| `fident` | **정렬된 구간에서의 서열 동일성** | 전체 서열이 아니다. `qcov` 와 같이 읽어야 한다. 폴드 히트는 0.13~0.20 이 정상 — 구조는 같고 서열은 다르다는 뜻 |
| `alnlen` | 정렬 길이 (잔기) | |
| `qcov` / `tcov` | 질의 / 대상의 **몇 %가 정렬에 들어갔나** | 낮으면 일부만 맞은 것이다 |
| `evalue` | 우연히 이만큼 맞을 기댓값 | 낮을수록 좋다 |
| `bits` | 정렬 점수 | 정렬 순위용 |
| `prob` | Foldseek 이 매긴 **상동일 확률** | |
| **`alntmscore`** | **TM-score** — 0~1, 구조가 얼마나 겹치나 | **우리가 쓰는 값.** 0.5 이상 같은 폴드, 0.9 이상 사실상 같은 구조. `--exact-tmscore 1` 없이 돌리면 1.0 을 넘는 근사값이 나온다 |
| `lddt` | 국소 거리 정확도 | 정렬 구간이 국소적으로 얼마나 잘 맞나 |

> **주의:** `alntmscore` 는 **정렬 구간 기준**이다. 짧게 정렬됐는데 그 구간이 잘 맞으면
> 높게 나올 수 있다. `qcov` 와 같이 봐야 하고, 확실히 하려면
> `qtmscore`·`ttmscore`(질의/대상 전체 길이 기준)를 같이 출력해 대조한다.
