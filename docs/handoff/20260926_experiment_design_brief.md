## 0. 한 문장

**다섯 개는 서로 다른 모델이 아니라, 하나의 질문을 네 조각으로 자르기 위한 대조군이다.**

질문은 이것이다 — **"유사도 구간 순서대로 순차 학습시키면 모델이 점점 좋아지는가?"**

이 질문에는 세 가지가 섞여 있다. 데이터가 늘어나서 좋아지는 것,
나눠서 배우기 때문에 좋아지는 것, 그리고 **유사도 순서대로** 배우기 때문에
좋아지는 것. 다섯 실험은 그 셋을 분리한다.

## 1. 무엇을 예측하는가

```
서열  →  [ ESM-1b, 얼려둠 ]  →  임베딩  →  [ 회귀 헤드 ]  →  ad_med_ds
```

| | |
|---|---|
| 입력 | 아미노산 서열 (구조도 도킹도 입력이 아니다) |
| 목표값 `y` | **`ad_med_ds`** — AutoDock-GPU 50런 **중앙값** (kcal/mol) |
| 학습되는 것 | 회귀 헤드만. ESM 가중치는 건드리지 않는다 |
| 주 지표 | 평가셋 55개의 **Spearman 순위상관** |

목표값이 낮을수록(더 음수) 결합이 강하다. 순위상관을 쓰므로 부호 방향만
일관되면 된다. **Pearson 이 아니라 Spearman 인 이유** — 최종 관심사는
"어느 상동체가 더 잘 붙나"의 순서이고, 점수의 절대 눈금은 도킹 엔진의
스케일이라 물리적 의미가 약하다.

> ⚠ `homolog_train.fasta` · `homolog_test.fasta` 헤더의 숫자는 지금 `fident`
> (ChCODH2 대비 identity) 가 들어 있다. **형식을 맞추기 위한 자리표시일 뿐이다.**
> 도킹이 끝나면 `dock_scores.tsv` 의 `ad_med_ds` 로 **반드시 교체**해야 한다.
> 교체하지 않으면 모델이 "서열로 identity 맞히기" 를 학습한다.

## 2. 데이터 — 모든 실험이 공유하는 바닥

### 2.1 세 덩어리

```
IPR010047  1,827 서열
   └ 70% identity 클러스터링 → 212 클러스터 (게이트 통과분)
        ├ core 212       클러스터당 medoid 1개
        │    ├ train 157
        │    └ test   55        ← 전 실험 · 전 곡선점에서 고정. 절대 불변
        └ expansion 109  학습 클러스터의 2번째 멤버.  D2 에서만 학습에 추가
```

**총 도킹 대상 321 = core 212 + expansion 109.**
고유 학습 서열은 157 + 109 = **266**, 평가 55, 합 321.

### 2.2 유사도 구간 (`cband`)

ChCODH2 대비 identity 를 클러스터 중앙값으로 잡고 10% 폭으로 끊었다.

| `cband` | core | train | test |
|---|---|---|---|
| `≥60` | 6 | 4 | 2 |
| `50-60` | 14 | 10 | 4 |
| `40-50` | 107 | 80 | 27 |
| `30-40` | 75 | 56 | 19 |
| `<30` | 10 | 7 | 3 |
| **합** | **212** | **157** | **55** |

구간 크기가 심하게 불균등하다. **이것은 데이터의 성질이고 고칠 수 없다** —
이 족에는 ChCODH2 와 가까운 친척이 거의 없다 (90% 이상 3~4개,
62.5–72.5% 는 완전히 비어 있음).

### 2.3 분할이 클러스터 단위인 이유

같은 클러스터는 서로 70% 이상 유사하므로 도킹 점수도 거의 같다.
서열 단위로 무작위 분할하면 **같은 클러스터의 형제가 학습과 평가로 갈려서,
외운 것을 다시 맞히는 평가**가 된다.

```
평가셋 클러스터 ∩ 학습셋 클러스터 = ∅        (실측 확인됨: 0개)
```

`expansion` 109개는 **학습 클러스터의 2번째 멤버만** 쓴다. 평가 클러스터에서는
뽑지 않았으므로, D2 에서 학습에 추가해도 누수가 생기지 않는다.

## 3. 왜 다섯 개인가 — 대조 구조

### 3.1 두 개의 축

| | 학습 방식 | 서열을 보는 순서 |
|---|---|---|
| **A** | **순차** (이어 학습) | **유사도 구간 순** |
| **B** | 한번에 | — (전량) |
| **C** | **순차** (이어 학습) | **무작위** |
| **D1** | 한번에 | — (크기만 변화) |
| **D2** | 한번에 | — (전량 + 확장) |

A 와 C 는 **순차성은 같고 순서만 다르다.** B 와 D1 은 순차성이 없다.

### 3.2 중첩 분해 — 이게 설계의 핵심

세 효과를 층층이 벗겨낸다.

```
D1          크기만 바뀐다. 매 점을 처음부터 학습.
             → 순수한 "데이터 양" 곡선

C           크기 + 순차성.  순서는 무작위.
             → C − D1 = "나눠서 이어 배우는 것" 자체의 효과

A           크기 + 순차성 + 유사도 순서.
             → A − C = "유사도 순서" 의 기여        ★ 우리가 보려는 것

B           n=157 전량 한 번에.
             → 순차 방식들의 종착점 기준선
```

**A − C 가 이 연구의 답이다.** C 가 없으면 A 와 B 의 차이가 순차성 때문인지
유사도 순서 때문인지 영원히 가릴 수 없다.

| 비교 | 답하는 것 |
|---|---|
| **A vs C** | **유사도 순서가 중요한가** (같은 크기, 같은 순차 방식) |
| A vs B | 순차적으로 배우는 게 한 번에 배우는 것보다 나은가 |
| C vs B | 순서와 무관하게 "나눠서 배우는 것" 자체의 효과 |
| D1 | 데이터 양의 포화점. 몇 개부터 성능이 안 오르는가 |
| D2 vs B | 클러스터당 대표 1개(CAP=1)로 충분했는가 |

### 3.3 A vs C 가 공정한 비교인 이유

C 는 **A 와 정확히 같은 크기**의 점을 갖는다.

```
A   4 → 14 → 94 → 150 → 157     (구간 경계가 크기를 결정)
C   4 → 14 → 94 → 150 → 157     (같은 크기, 무작위 순서)
```

같은 시점에 같은 개수를 본 두 모델을 맞대므로, 차이는 **본 순서**뿐이다.

### 3.4 C 와 D1 의 표집 방식이 다른 이유

| | 표집 | 왜 |
|---|---|---|
| **C** | **비층화** 단순 셔플 | A 가 "구간 순서대로" 이므로 대조는 "아무 순서로" 여야 한다. 층화하면 각 단계가 구간 비율을 유지하게 되어 A 를 흐릿하게 닮아버린다 |
| **D1** | **층화** (구간 비율 유지) | "데이터가 얼마나 필요한가" 를 묻는다. 각 크기에서 구성이 전체를 대표해야 곡선이 "양" 만의 함수가 된다 |

이걸 반대로 하면 두 실험이 각자의 질문에 답하지 못한다.
**C 를 층화하면 A 와의 차이가 줄어들어 순서 효과를 과소평가하고,
D1 을 비층화하면 작은 n 에서 구간 구성이 튀어 곡선이 표집 잡음에 묻힌다.**

### 3.5 둘 다 중첩(nested)인 이유

```
step1 ⊂ step2 ⊂ step3 ⊂ … ⊂ step_last
```

중첩이 아니면 n=40 이 n=20 보다 나쁠 수 있다 — 하필 어려운 서열을 뽑았을
때다. 그러면 곡선이 오르내리고 "포화점" 을 읽을 수 없다.
중첩이면 **데이터가 줄어들어 나빠지는 일은 없으므로, 내려가는 구간은
반드시 다른 원인**이다.

### 3.6 반복 횟수가 다른 이유

| | 반복 | 왜 |
|---|---|---|
| A | 1 | 순서가 구간으로 **결정되어 있다.** 무작위성이 없다 |
| B | 1 | 157개 전량. 뽑을 게 없다 |
| **C** | **5** | 무작위 셔플. 한 번만 돌리면 그 셔플의 운을 본 것 |
| **D1** | **5** | 층화 무작위 표집. 같은 이유 |
| D2 | 1 | 266개 전량 |

C·D1 의 오차막대는 **표집 변동**이다. A·B·D2 는 점 하나뿐이므로,
그 점이 C 의 오차막대 밖에 있는지로 유의성을 판단한다.

**학습 실행 횟수** = A 5 + B 1 + C 25 + D1 40 + D2 1 = **72회**
ESM 임베딩은 서열당 한 번만 계산해 캐시한다 (고유 서열 321개).

## 4. 각 실험 상세

### 4.1 A — 유사도 구간 순차 학습 ★ 주 실험

```
step 1   ≥60      누적    4      ← 학습 성립 안 됨 (4.6 참조)
step 2   50-60    누적   14
step 3   40-50    누적   94
step 4   30-40    누적  150
step 5   <30      누적  157
```

높은 유사도부터 낮은 쪽으로 내려간다. **가까운 친척으로 기초를 잡고
점점 먼 것으로 확장할 때 모델이 좋아지는가**를 본다.

기대하는 그림 — Spearman 이 단계마다 오르고, 마지막에 B 를 넘거나
최소한 같아진다. 오르지 않으면 "유사도 순서는 도움이 안 된다" 가 결과다.
**그것도 유효한 결과다.**

### 4.2 B — 상한 기준선

157개를 한 번에 학습한다. 점 하나.
**A·C 의 종착점이 여기와 같은지 다른지가 순차 학습의 존재 증명이다.**

### 4.3 C — 무작위 순차 (A 의 대조군)

A 와 같은 크기, 무작위 순서, 5회 반복. **비층화 셔플.**
A 가 C 의 오차막대 위로 벗어나야 "유사도 순서" 효과가 있는 것이다.

### 4.4 D1 — 데이터 양 곡선

```
n = 20 · 40 · 60 · 80 · 100 · 120 · 140 · 157      8점 × 5반복
```

매 점을 **처음부터** 학습한다. 층화 중첩 표집.
곡선이 평평해지는 지점이 "이 정도 데이터면 충분" 이다.

> **주의** — D1 의 격자(20·40·…)는 A·C 의 크기(4·14·94·150·157)와
> 일치하지 않는다. A↔C 비교는 정확하지만 **A↔D1 비교는 보간이 필요**하다.
> 정확히 맞대야 하면 D1 격자에 A 의 크기를 추가해 재생성한다
> (`experiment_sets.tsv` 를 다시 만들어야 하므로 **라벨을 보기 전에** 결정할 것).

### 4.5 D2 — CAP=1 이 충분했는가

```
학습 157 + 확장 109 = 266        평가는 그대로 55
```

확장 109개는 학습 클러스터의 2번째 멤버다. 대표와 70% 이상 유사하므로
**이론적으로는 거의 같은 라벨**을 갖는다.

| D2 결과 | 해석 |
|---|---|
| B 와 비슷 | **CAP=1 이 옳았다.** 형제 서열은 중복 정보 — 손실함수에 표를 더 던질 뿐 |
| B 보다 확실히 좋음 | 클러스터 내 변이에도 정보가 있다. CAP 상향 재검토 |
| B 보다 나쁨 | 형제 서열의 라벨 잡음이 학습을 방해. 노이즈 바닥과 함께 해석 |

확장분은 **동시에 노이즈 바닥 측정에 쓰인다** — 대표와 2번째 멤버의
점수 차이가 상동체 도킹의 잡음 크기다. 도킹 비용이 0 추가라 함께 돌렸다.

### 4.6 A 의 첫 점은 분석에서 합친다

`≥60` 이 4개라 학습이 성립하지 않는다. **분석 단계에서 앞 두 구간을 합쳐
n=14 에서 시작한다.** 선정과 `experiment_sets.tsv` 는 그대로 둔다 —
파일을 고치면 재현 경로가 끊긴다.

A 의 증분이 +4 / +10 / +80 / +56 / +7 로 불균등한 것은 **x축 모양의 문제이지
비교의 문제가 아니다.** C 가 같은 크기를 갖기 때문이다.

## 5. 이어 학습 — A 가 성립하기 위한 전제

"순차 학습" 에는 전혀 다른 두 가지가 있다.

| | 무엇 | 결과 |
|---|---|---|
| **누적 재학습** | 단계마다 처음부터 다시 적합 | 그냥 학습곡선. **마지막 점이 B 와 같아져 대비가 사라진다** |
| **이어 학습** (warm start) | 이전 모델 가중치를 물려받아 다음 구간만 추가 | B 와 다른 결과가 나올 수 있다 |

**A 의 요점은 이어 학습이다.** 누적 재학습으로 돌리면 A 는 D1 의 다른
격자판이 될 뿐이고, "순서" 를 볼 수 없다.

### 5.1 회귀 헤드가 이어 학습을 지원해야 한다

| 헤드 | 이어 학습 |
|---|---|
| Ridge · Lasso · SVR | **불가능** — `fit()` 마다 닫힌 해를 처음부터 다시 풂 |
| RandomForest · XGBoost | 사실상 불가능 |
| `SGDRegressor` | 가능 — `partial_fit()` |
| 작은 MLP (PyTorch) | 가능 — 가중치와 optimizer 상태를 유지 |

**SeekRank 회귀 헤드가 무엇인지 먼저 확인할 것.**

```bash
grep -rn "Ridge\|SVR\|RandomForest\|XGB\|SGDRegressor\|MLPRegressor\|nn\.Linear\|partial_fit\|warm_start" \
     <SeekRank 경로> --include=*.py
```

닫힌 해 계열이면 작은 MLP 로 교체한다. 학습 표본이 157개뿐이라 작아야 한다.

```
Linear(1280 → 32) → ReLU → Dropout(0.2) → Linear(32 → 1)
```

**그리고 B 도 같은 헤드로 돌려야 한다.** A 와 B 가 다른 모델이면
"순차 학습의 효과" 가 아니라 "모델 차이" 를 재게 된다.

### 5.2 이어 학습에서 반드시 고정할 것

| 항목 | 이유 |
|---|---|
| 단계별 epoch 수 | 뒤 단계에 더 많이 돌리면 "순서" 가 아니라 "학습량" 효과가 섞인다 |
| learning rate 스케줄 | 단계마다 리셋할지 이어갈지 정해서 A·C 에 동일 적용 |
| 표준화 통계 | 임베딩 정규화를 쓰면 **step1 의 통계로 고정**. 단계마다 다시 계산하면 평가셋 정보가 새어들 수 있다 |
| `random_state` | C·D1 의 반복이 재현되어야 한다. 시드 `20260916` |

## 6. 검산 — 학습 시작 전에 확인할 것

### 6.1 종점이 겹치는가

**누적 재학습**으로 돌린다면 아래 셋은 같은 데이터로 같은 모델을 만든다.

```
B         n=157
C step5   n=157
D1 step8  n=157
```

결과가 다르면 `random_state` 가 안 잡힌 것이다.
**이어 학습**이라면 C step5 는 B 와 달라야 정상이고, 그것이 실험의 요점이다.

### 6.2 D1 step8 의 5회 반복

n=157 에서는 다섯 반복이 **전부 같은 집합**이다. 그래도 결과가 흔들리면
그건 표집이 아니라 **모델 자체의 변동**(초기화·드롭아웃·배치 순서)이다.
그 몫을 다른 점들의 오차막대에서 빼면 순수한 표집 변동이 남는다.
**이 값을 먼저 재두면 이후 모든 오차막대의 해석이 달라진다.**

### 6.3 파일 무결성

```python
import pandas as pd
E = pd.read_csv(f"{SPLIT}/experiment_sets.tsv", sep="\t")
D = pd.read_csv(f"{SPLIT}/dock_targets.tsv",   sep="\t")
TEST = set(D.loc[D.split == "test", "accession"])

# ① 평가셋이 어떤 학습 집합에도 없어야 한다
print("평가셋 혼입:", len(set(E.accession) & TEST), "  ← 0")

# ② 중첩 구조
for (exp, rep), g in E[E.exp.isin(["A", "C", "D1"])].groupby(["exp", "rep"]):
    sets = {st: set(x.accession) for st, x in g.groupby("step")}
    ks = sorted(sets)
    bad = [(a, b) for a, b in zip(ks, ks[1:]) if not sets[a] <= sets[b]]
    if bad:
        print(f"중첩 깨짐 {exp} rep{rep}: {bad}")

# ③ 단계별 크기
print(E.groupby(["exp", "rep", "step"]).size()
        .unstack("step").fillna(0).astype(int).to_string())

# ④ 고유 학습 서열 = 266
print("고유 학습 서열:", E.accession.nunique(), "  ← 266")
```

네 개가 전부 통과해야 학습을 시작한다.

## 8. 라벨을 손볼지 — 도킹 후 결정할 것

조립 품질이 유사도와 교락되어 있다.

```
cband   RMSD   충돌   center_dev
≥60     0.61    1.4      0.14
<30     2.51   22.9      0.65
```

유사도가 낮을수록 조립이 나빠진다. 따라서 도킹 점수에는
**결합의 차이 + 조립 인공물**이 같은 방향으로 섞여 들어올 수 있다.

모델은 서열만 보므로 이 인공물을 볼 수 없다. 두 가지 길이 있다.

| | 방법 | 장단 |
|---|---|---|
| **주 분석** | 원본 `ad_med_ds` 로 학습 | 해석이 단순. 인공물이 섞인 채로 남음 |
| **민감도 분석** | 기술 공변량으로 **잔차화**한 라벨로 재학습 | 인공물을 뺀 값. 무엇을 예측하는지가 바뀜 |

잔차화는 이렇게 한다.

```
y_resid = residual( ad_med_ds ~ RMSD + center_dev + 임계충돌 + pLDDT
                                + struct_source + mode )
```

> **`cband` 는 절대 잔차화 대상에 넣지 않는다.** 유사도는 정당한 예측 인자다.
> 그것으로 잔차화하면 우리가 보려는 신호를 직접 지우는 셈이 된다.

**주 분석은 원본으로 하고, A 의 추세가 잔차화 라벨에서도 살아 있는지를
민감도로 보고한다.** 둘이 갈리면 그 자체가 보고할 결과다.

공변량은 `$SPLIT/assembly_manifest_all.tsv` 에 있다.

### 10.1 `experiment_sets.tsv` 구조

| 컬럼 | 뜻 |
|---|---|
| `exp` | `A` / `B` / `C` / `D1` / `D2` |
| `step` | 곡선의 몇 번째 점인가 |

| `accession` | 학습에 넣을 서열 |
| `label` | 구간명 또는 크기 표기 |

`(exp, step, rep)` 로 묶으면 그 조건의 학습 서열 목록이 나온다.

```python
import pandas as pd
E = pd.read_csv(f"{SPLIT}/experiment_sets.tsv", sep="\t")

for (exp, rep), g in E.groupby(["exp", "rep"]):
    for step, gs in g.groupby("step"):
        train = gs.sort_values("rank").accession.tolist()
        # ── 여기서 학습. 이어 학습이면 이전 step 의 모델을 물려받는다 ──
        # 평가는 언제나 같은 55개
```

`rank` 는 **이어 학습에서 서열을 먹이는 순서**다. A 는 구간 순,
C 는 셔플 순이다. 배치 학습(B·D1·D2)에서는 무시해도 된다.

## 11. 결과를 어떻게 보고하는가

주 그림 하나면 된다.

```
x축   학습 서열 수 n
y축   평가셋 55개의 Spearman

  ─── A   유사도 구간 순차          (점 5개, 선)
  ┈┈┈ C   무작위 순차, 5반복        (평균 + 오차막대)
  ─ ─ D1  크기만, 5반복             (평균 + 오차막대)
   ●  B   n=157 한번에
   ▲  D2  n=266
```

읽는 법.

| 보이는 것 | 결론 |
|---|---|
| A 가 C 의 오차막대 **위로** 벗어난다 | **유사도 순서가 기여한다** ★ |
| A 와 C 가 겹친다 | 순차성은 효과가 있어도 순서는 무관 |
| A·C 가 D1 위에 있다 | 나눠서 이어 배우는 것 자체가 효과 |
| A·C 종점이 B 와 같다 | 이어 학습이 아니라 누적 재학습이었다 (5절 확인) |
| D1 이 n=100 부터 평평 | 그 이상은 데이터가 남는다 |
| D2 ≈ B | CAP=1 이 옳았다 |

**노이즈 바닥을 먼저 보고한다.** 확장 109쌍의 `|score(대표) − score(2번째)|`
가 상동체 도킹의 잡음 크기다. **그 값보다 작은 성능 차이는 주장할 수 없다.**
이 숫자 없이 Spearman 을 내면 "구조 예측 오차보다 큰 차이인가" 에 답할 수 없다.
