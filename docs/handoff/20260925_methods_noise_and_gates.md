## 1. 용어 — 쉬운 설명과 논문용 표현

| 용어 | 쉬운 설명 | 논문용 표현 (영) |
|---|---|---|
| **노이즈 (noise)** | AutoDock은 무작위로 리간드를 놓아보며 최적 자리를 찾기 때문에 **돌릴 때마다 답이 조금씩 달라진다.** 그 흔들림. | stochastic run-to-run variability of the docking search |
| **노이즈 바닥 (noise floor)** | 그 흔들림의 크기를 실제로 재서 얻은 숫자. **우리 자의 눈금 간격.** 이보다 작은 차이는 읽을 수 없다. | empirical noise floor; technical resolution limit |
| **SD (표준편차)** | 숫자들이 평균에서 얼마나 흩어져 있나. 크면 넓게 퍼짐, 작으면 한 곳에 모임. | standard deviation |
| **IQR (사분위범위)** | 값을 줄 세워 아래 25%·위 25%를 잘라낸 **가운데 50%의 폭.** SD는 극단값 몇 개에 부풀려지므로, 대다수가 어디 모여 있는지 보려면 IQR을 같이 본다. | interquartile range |
| **SNR (신호 대 잡음 비)** | **"진짜 차이가 측정 흔들림보다 몇 배나 큰가."** 라디오에서 방송이 지글지글보다 훨씬 크면 잘 들리고, 비슷하면 못 알아듣는 것과 같다. | signal-to-noise ratio |
| **라벨 (label)** | 모델에게 정답으로 주는 값. 우리 경우 **도킹 점수 `ad_med_ds`**. | target variable / label |
| **사전 게이트 (pre-flight gate)** | 학습을 시작하기 **전에** "이 데이터로 배울 수 있는가"를 검사하는 단계. | pre-registered feasibility gate |

### 비유 세 개 (발표용)

1. **자(ruler) 비유** — 노이즈 바닥 0.280은 **자의 눈금 간격**이다. 0.18 차이는 눈금보다 작아서 같은 값으로 읽힌다.
2. **라디오 비유** — SNR은 방송/지글지글 비율이다. 321 상동체는 또렷한 방송, 288 변이체는 지글지글에 묻힌 희미한 목소리.
3. **문제집 비유** — 609문제 중 288문제가 사실상 같은 문제이고 답도 같으면, 모델은 그 답만 외우고 나머지 321문제를 못 풀게 된다.

## 2. 왜 게이트를 먼저 했나

최종 목표는 **서열 → 도킹 점수를 예측하는 회귀 모델**이다. 모델은 "이 서열 → 이 점수" 짝을 수백 개 보고 규칙을 배운다. 그런데 **점수들이 서로 구별되지 않으면 배울 것이 없다.**

이 검사를 학습 뒤로 미루면, 성능이 안 나올 때 원인이
(a) 특징 설계 문제인지 (b) 모델 선택 문제인지 (c) 애초에 라벨에 신호가 없어서인지
구별할 수 없어 몇 주를 소모한다. 그래서 **학습 전에** 세 가지를 물었다.

```
게이트 1   변이체 288개의 점수가 서로 구별 가능한가?        → 288을 학습셋에 넣을지 결정
게이트 2   ESM 프로그램이 우리 단백질을 버리지 않는가?       → 어느 ESM 모델을 쓸지 결정
게이트 3   공개 DB 검색 결과가 쓸 수 있는 형태인가?          → ColabFoldDB 트랙 진행 여부 결정
```

세 게이트는 서로 독립이므로 동시에 수행했다. 계산 비용은 합쳐서 5분 미만이다.

## 3. 노이즈 바닥의 측정 — 방법과 값

### 측정 원리

> 서열이 거의 같은 단백질 쌍(같은 MMseqs2 클러스터)을 찾는다.
> 이 쌍은 **원래 도킹 점수가 같아야 정상**이다.
> 실제로 재보니 차이가 났다. 그 차이가 곧 측정 흔들림의 크기다.

이 값은 **기술적 잡음의 상한(upper bound)** 이다. 관측된 차이에는 잡음뿐 아니라 두 서열 간의 실제 미세한 차이도 섞여 있으므로, 순수 잡음은 이보다 작거나 같다. 상한을 쓰는 것이 보수적이고 안전하다.

### 실측값

| 엔진 | 동일클러스터 쌍 \|Δscore\| 중앙값 | 평균 | 90분위 | SNR (정본 정의) | 판정 |
|---|---|---|---|---|---|
| **AutoDock-GPU** | **0.280** kcal/mol | — | — | **3.4** | 진행 가능 |
| RxDock | 1.311 | 2.088 | 4.826 | 1.2 | 라벨이 잡음에 묻힘 → 기각 |

---

### ⚠ SNR 정의가 두 가지 있다 — 혼동 주의

문서·셀에 **서로 다른 두 SNR**이 등장한다. 숫자가 다르다고 오류가 아니다.

| | 정의 | AutoDock 상동체 | 변이체 288 | 성격 |
|---|---|---|---|---|
| **정본 SNR**<br>(셀 9) | Var(between) ÷ **mean(within²)** | **3.4** | — | 보수적. 쌍 차이의 제곱 평균을 쓰므로 꼬리에 민감 |
| **간이 SNR**<br>(게이트 셀 ①) | (SD ÷ **median\|Δ\|**)² = (SD ÷ 0.280)² | **11.54** | **1.13** | 낙관적. 빠른 스크리닝 전용 |

**보고 규칙:** 논문·인계문서에는 **정본 SNR(3.4 / 1.2)을 주 지표로** 쓴다. 간이 SNR은 "학습셋 후보를 빠르게 걸러내는 스크리닝"으로만 언급한다. 변이체 288의 간이 SNR이 1.13이므로, 정본 정의로 계산하면 **1.13보다 더 낮다** — 즉 판정 방향은 바뀌지 않는다.

## 5. 변이체 288의 문제 — 원리

### 그림

```
도킹 점수 (왼쪽 = EV 가 더 잘 붙음, kcal/mol)

  -10      -9       -8       -7       -6       -5       -4       -3
   |--------|--------|--------|--------|--------|--------|--------|

상동체 321
   ●━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━●
   전체 폭 6.83                     가운데 50% ┣━━━━━━━━┫ 1.02   → 눈금 3.6칸

변이체 288
                              ●━━━━━━━━━━━━━━━●
                              전체 폭 1.85  가운데 50% ┣┫ 0.18  → 눈금 0.65칸

우리 자의 눈금 (노이즈 바닥)                  ├──┤ 0.28
```

### 왜 문제인가 — 두 겹의 중복

변이체 288개는 전부 **ChCODH2(633 잔기) 한 단백질에서 아미노산 하나만 바꾼 것**이다. 따라서:

1. **입력이 거의 같다.** ESM 임베딩은 전 잔기를 평균(mean-pool)하므로, 633개 중 1개가 바뀐 것은 1280차원 벡터를 거의 움직이지 않는다 → 모델 입장에서 **같은 좌표**.
2. **출력도 거의 같다.** 라벨의 가운데 50%가 노이즈 바닥 안에 있다 → 모델 입장에서 **같은 값**.

그 결과 그냥 합치면:

```
학습 재료 609개 = 상동체 321 (서로 다 다름) + 변이체 288 (한 좌표에 뭉침)
                                                 ↑ 전체의 47%
```

Random Forest의 부트스트랩 표집은 **매 트리마다 표본의 약 절반을 그 한 좌표에서** 뽑게 되고, ChCODH2 근방의 모든 예측이 −4.43에 달라붙는다. 상동체가 만든 −9.89 ~ −3.06의 넓은 신호가 희석된다.

### 다만 전부 버릴 것은 아니다

변이체의 **전체 폭은 1.85**이다. 가운데는 뭉쳐 있으나 꼬리(−5.96까지)는 노이즈 바닥을 크게 넘는다.

> **대다수는 무신호, 소수 꼬리는 진짜 신호.**

따라서 쟁점은 "넣는가/빼는가"가 아니라 **"어떻게 넣는가"** 이다.

⚠ **하지 말 것:** "노이즈 바닥을 넘는 변이만 골라 넣기"는 **종속변수(라벨) 값으로 표본을 선별**하는 것이므로 informative censoring(정보성 절단)이다. 라벨 분포의 꼬리만 남겨 모델을 왜곡한다. 이 프로젝트에서 이미 한 번 같은 실수를 지적받은 바 있다(§8).

## 6. 해법 — 3단계 설계

문제의 근원은 **특징 표현(mean-pool)이 점돌연변이를 구별하지 못하는 것**이다. 표본을 고르는 대신 **특징을 고친다.**

| 단계 | 학습셋 | 특징 | 목적 |
|---|---|---|---|
| **S1** | 상동체 321만 | mean-pool ESM | 깨끗한 기준선. ρ_homolog(55) 확보 |
| **S2** | 321 + 288 | mean-pool + **288에 sample_weight 하향** | ρ_homolog가 S1 대비 하락하는지 = 288이 해치는지 측정 |
| **S3** | 321 + 288 | **+ 결합부위 잔기 수준 기술자** | 288이 서로 구별되게 하여 정보를 살림 (본래 목표) |

S1·S2는 S3이 실제로 개선인지 증명하기 위한 **대조군**이다. S3만 돌리면 개선 여부를 말할 수 없다.

### S3의 특징 설계

```
feature = [ mean-pool ESM → PCA 20차원 ]        ← 전역 서열 맥락 (상동체 구분)
        + [ K개 결합부위 위치 × 4 기술자 ]        ← 국소 치환 (변이체 구분)
                                                   전하 / 부피 / 방향족 / 소수성
```

- **K는 이미 정해져 있다.** `engines_288_CA_r15.csv`의 `pos` 컬럼 고유값이 **16개** — 실험이 건드린 위치가 그 16곳이다.
- 상동체에서 대응 위치는 `master_1827.tsv`의 `f41_pos` 앵커 + MSA로 매핑.
- 차원: K=16이면 20 + 64 = **84차원**. n=609에 RFR을 쓰기에 적절하다. mean-pool 1280차원 원본을 그대로 쓰면 과적합이다.
- **PCA와 층 선택은 학습셋에서만 fit.** 시험군 55개는 절대 사용하지 않는다(§9 누출 항목 참조).
- 이 설계는 전하 변화(`dchg`)를 명시적으로 포함하므로, 성능 보고 시 **dchg 단독 모델의 ρ를 기준선으로 병기**하여 잔차 개선분을 보여야 한다.

### 진단용 추가 실험

- **집단 지시자(group indicator) 특징을 넣은 모델**을 하나 더 돌린다.
  - 성능이 변하지 않으면 → 두 집단이 같은 특징공간을 공유한다는 증거.
  - 성능이 크게 오르면 → 모델이 "어느 집합에서 왔는지"만 학습하고 있다는 신호 → 본 모델에서 제외.
- **288 내부 임베딩 코사인거리 vs 321 내부 코사인거리** 분포 비교. 288 중앙값이 321의 1/10 이하이면 mean-pool 단독 사용 불가가 확정된다.

## 7. 논문 Methods 문단 초안

### 한글

> **도킹 점수의 기술적 재현성 평가.** AutoDock-GPU의 탐색은 확률적이므로, 각 수용체에 대해 50회 독립 실행 후 중앙값을 대표값으로 사용하였다. 잔여 측정 변동의 크기를 정량하기 위해, 동일 MMseqs2 클러스터에 속하는 상동체 쌍(서열 동일성이 높아 결합 자유에너지가 실질적으로 동일할 것으로 기대되는 쌍)의 점수 차 절대값을 집계하였다. 그 중앙값 0.280 kcal/mol을 기술적 잡음의 상한, 즉 본 연구의 유효 분해능으로 정의하였다. 동일 절차를 RxDock에 적용한 결과 1.311 kcal/mol(평균 2.088, 90분위 4.826)이 얻어졌으며, 집단 간 분산 대 잡음 비(SNR)가 AutoDock 3.4, RxDock 1.2로 산출되어 이후 분석은 AutoDock 점수만을 라벨로 사용하였다.
>
> **학습셋 적격성 사전 검사.** 회귀 모델 학습에 앞서, 각 데이터 집단의 라벨 분산이 위 분해능을 초과하는지 검사하였다. 상동체 321개는 IQR 1.020 kcal/mol로 분해능의 3.6배에 해당하였으나, ChCODH2 점돌연변이 288개는 IQR 0.183 kcal/mol로 분해능 미만이었다. 이는 변이체 집단의 중앙 50%가 본 파이프라인으로는 구별되지 않음을 뜻한다. 따라서 두 집단을 단순 병합하지 않고, (i) 상동체 단독, (ii) 변이체 표본가중 하향 병합, (iii) 결합부위 잔기 수준 기술자를 추가한 병합의 세 조건을 비교하는 설계를 채택하였다.

### English

> **Technical reproducibility of docking scores.** Because the AutoDock-GPU search is stochastic, each receptor was docked in 50 independent runs and the median binding energy was taken as the representative value. To quantify the residual measurement variability, we collected the absolute score differences of homolog pairs belonging to the same MMseqs2 cluster — pairs whose high sequence identity implies essentially identical binding free energies. The median of this distribution, 0.280 kcal/mol, was defined as an upper bound on technical noise and thus the effective resolution of the assay. The same procedure applied to RxDock yielded 1.311 kcal/mol (mean 2.088, 90th percentile 4.826). The corresponding between-group-variance-to-noise ratios were 3.4 for AutoDock and 1.2 for RxDock; accordingly, only AutoDock scores were used as regression labels.
>
> **Pre-flight eligibility screening of training sets.** Before model training, we tested whether the label variance of each data group exceeded the assay resolution. The 321 homologs spanned an IQR of 1.020 kcal/mol, 3.6-fold the resolution, whereas the 288 ChCODH2 point variants spanned an IQR of only 0.183 kcal/mol, below the resolution — indicating that the central 50% of the variant set is not resolvable by this pipeline. We therefore avoided naive pooling and instead compared three conditions: (i) homologs only, (ii) pooled with down-weighted variant samples, and (iii) pooled with additional binding-site residue-level descriptors.

## 13.2 근거 네 개

### ① 24차원 조성이 1280차원 ESM 과 동등

| 특징 | 차원 | `rho_xval` (학습군 157, 5-fold × 2반복) |
|---|---|---|
| 아미노산 조성 | **24** | **0.4218 ± 0.1471** |

**층 33(최고수준 문맥)은 조성보다 오히려 나쁘다 (−0.045).**

### ② 평가셋에서는 층 0 이 최고 — 층 0 = 조성의 선형 변환

| 층 | `rho_xval` (학습군) | `rho_test` (평가군 55) |
|---|---|---|
| **0** | 0.3500 | **0.6190** ← 최고 |
| 1 | 0.3619 | 0.6105 |
| 2 | **0.4438** ← 학습군 최고 | 0.5773 |
| 3 | 0.4161 | 0.5690 |
| 4 | 0.3316 | 0.5628 |
| 6 | 0.3983 | 0.4622 |
| 33 | 0.3765 | 0.5407 |

**층 0 은 ESM 의 토큰 임베딩 룩업 테이블을 mean-pool 한 것이다.** 즉

```
mean-pool(층 0) = Σ (아미노산 비율 × 그 아미노산의 고정 벡터)
```

**정보량이 아미노산 조성과 정확히 같다** (차원은 1280이지만 자유도는 20).
따라서 "평가셋 최고가 층 0" 은 **"조성이 최고다" 와 같은 말**이다.

평가셋 성능이 층이 깊어질수록 대체로 감소한다 (0.619 → 0.611 → 0.577 → … ).

### ③ 선택 편향은 기각됐다 — 순열 검정

34개 층 중 최댓값을 뽑으면 진짜 성능이 모두 같아도 가장 운 좋은 것이 뽑힌다
(동전 34개를 10번씩 던져 앞면 최다를 뽑는 것과 같다). 그 부풀림을 실측했다.

**라벨을 무작위로 섞어(신호 0) 34층 중 최댓값을 교차검증으로 고르기 × 5회:**

```
+0.1530  +0.0753  +0.1851  +0.0435  +0.1620
평균 +0.1238   최대 +0.1851
```

**실제 관측 최댓값 0.4438 은 잡음 최댓값(0.1851)의 2.4배.**
→ 층 2 의 성능은 선택 편향으로 설명되지 않는다. **진짜 신호다.**

학습군 교차검증(31개씩 평가)이 이 정도이므로, **평가셋(55개)로 34층 중 최고를 고르면
부풀림이 더 커진다** — 별도 시뮬레이션에서 n=55·34층에서 잡음만으로 ρ 0.283 이 나왔다.
**그래서 층·특징 선택은 학습군 교차검증으로만 하고, 평가셋 표는 탐색적 보고로만 쓴다.**

| 재현 | ESM-1b 7.3 GB 필요 | **의존성 없음** |
| 해석 | 불가 | **어느 아미노산이 기여하는지 확인 가능** |

**단, 특징 선택도 학습군 교차검증으로 한다.** 교차검증으로는 층 2(0.4438)가 조성(0.4218)을
이기므로, 규칙대로면 주 모델은 층 2 다. 조성은 **동등함을 보고하는 대조**이자
**대규모 채점용 대안**으로 둔다.

## 13.6 재현성 — `n_jobs=-1` 의 부동소수점 비결정성

층 선택을 동일 시드·동일 데이터·동일 코드로 두 번 돌린 결과:

```
34개 층 중 32개가 소수 6자리까지 동일
층 1   0.361783 → 0.361919   (차 0.000136)
층 31  0.2930   → 0.2931
선택된 층 2, rho_xval 0.443768 — 완전 동일
```

**원인:** `RandomForestRegressor(n_jobs=-1)` 의 예측 단계에서 나무 100개의 출력을
공유 배열에 누적하는데, 그 **합산 순서가 스레드 스케줄링에 따라 달라진다.**
부동소수점 덧셈은 결합법칙을 만족하지 않으므로 마지막 비트가 흔들리고,
그것이 순위상관의 동점 경계에 걸리면 소수 4자리에서 드러난다.
나무 자체는 `random_state` 고정으로 동일하다.

**영향:** 흔들림 0.0001 vs 판정할 효과 크기 0.02~0.17, 오차막대 0.03~0.14.
**효과 크기의 1/200 수준이므로 어떤 결론도 뒤집지 못한다.** 순위도 변하지 않았다.

**대응:** `n_jobs=1` 로 하면 비트 단위 재현이 되나 학습 284회가 4~8배 느려진다.
그 비용을 쓰지 않고, **논문 Methods 에 한 줄로 명시**한다.

> 학습은 `n_jobs=-1` 로 병렬 수행하였다. 병렬 예측 합산 순서에 따른 부동소수점
> 차이로 순위상관이 약 1×10⁻⁴ 수준에서 변동하며, 이는 보고된 효과 크기보다
> 두 자리 이상 작다.

| **`tier`, `split`, `cluster`, `arch`, `mode`, `struct_source`** | 상동체 분류·분할·조립 관련 메타데이터 |
| **`fident`** | fraction identical. MMseqs2가 주는 **서열 동일성 비율**. 현재 학습·시험 FASTA 헤더에 **자리표시자로 들어있는 값** → 도킹 점수로 교체해야 함 (T4) |
| **`ad_med_ds` 부호** | AutoDock은 값이 **낮을수록 잘 붙음**. SeekRank는 **높은 값을 좋은 것으로** 정렬하므로 FASTA 라벨에는 **`−ad_med_ds`(부호 반전)** 를 넣는다 |
