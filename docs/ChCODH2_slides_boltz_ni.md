# 발표 구성 — Boltz Ni 배위 등급

Folddisco 슬라이드(7p) → Foldseek 슬라이드(8p) 다음에 올 **Track B** 부분.
슬라이드별로 **올릴 것 / 숫자 / 예상 질문**을 적었다.

전체 흐름은 하나다:
**"두 지표를 버리고 하나를 택했다. 택한 이유는 재현성이다."**

---

## S1. Why co-folding with Ni

**올릴 것**

```
ChCODH2  +  candidate protein  +  Ni²⁺ (CCD: NI)   →  Boltz-2
```

- 공진화(RF2-PPI)가 대조군에서 떨어진 뒤의 대안
- Track B = MG1655 대비 **low-similarity + strain-specific 326개**
  (직교체가 적어 MSA 가 안 쌓이는 것들 → 공진화 대신 구조 예측)
- 설정: `--use_msa_server --max_msa_seqs 2048 --recycling_steps 3 --diffusion_samples 1`
- 326 → 길이 제한(합 ≤ 1,830) 323 → OOM 2건 → **321 완료**
- focus 27 · 타 균주 비교 50 · 반복 13(65 구조) = 총 **411 구조**

**예상 질문** — *"왜 326개만?"*
→ 그것이 이 파이프라인의 한계이고, 발표에서 먼저 말하는 편이 낫다.
identical + high-similarity **3,746개는 평가받지 못했다**(S8 에서 다룬다).

## S2. 버린 지표 둘 — 여기가 방법론의 핵심

**올릴 것 (표 하나로)**

| 지표 | 무엇을 재는가 | 대조군 | 판정 |
|---|---|---|---|
| `ipTM` | 모델이 **자기 계면을 자평**한 값 | CooC1 = **0.300** 인데 후보 8개가 전부 그 위 | **폐기** |
| `ligand_ipTM` | 리간드 배치 신뢰도 | 계면 배치 **0 / 348**, 단백질 길이와 **ρ = −0.807** | **폐기** |

**말할 것**

> ipTM 은 "답을 아는 입력"이 후보보다 낮게 나왔다. 눈금이 반대로 서 있었다.
> ligand_ipTM 은 계면을 재는 줄 알았는데 **길이를 재고 있었다.**

**Ni 이 놓인 위치 (348 구조)**

| 위치 | 수 |
|---|---|
| 계면 (양쪽 사슬이 같이 배위) | **0** |
| ChCODH2 쪽만 | 335 |
| 후보 쪽만 | 13 |

**→ 전달 복합체는 한 번도 모델링되지 않았다.**

**예상 질문** — *"그럼 co-folding 이 실패한 것 아닌가?"*
→ 계면 복합체로는 실패했다. 다만 **배위 거리 자체는 타당하다** — 평균 2.24 Å
(1.97–3.27). Ni–S 2.2 / Ni–N 2.1 근처다. 모델이 아무 데나 얹은 것이 아니라
진짜 금속 자리를 골랐다. 그래서 "자리의 질"만 축으로 남긴다.

## S3. 남긴 지표 — Ni 배위 좌표는 재현된다

**올릴 것**

| 단백질 | BL21 | MG1655 | Y19 | 배위 잔기 |
|---|---|---|---|---|
| HslO | 2.18 | — | 2.17 | CYS232 CYS230 CYS263 CYS266 (동일) |
| HisB | 1.91 | 1.92 | 1.86 | CYS103 HIS95 CYS101 CYS93 (동일) |
| Tgt | 2.14 | 2.12 | 2.14 | HIS333 CYS302 CYS304 CYS307 (동일) |
| PhnP | 2.05 | 2.08 | 2.00 | ASP164 HIS78 … |

**Δ 0.01–0.08 Å** — 서로 다른 배치, 다른 GPU, 다른 균주의 직교체인데 같은 잔기를
같은 거리로 잡는다. ipTM 이 같은 입력끼리 0.28 씩 벌어지는 것과 정반대다.

> **이것이 이 축을 믿는 유일한 근거다.** 재현되는 것만 쓴다.

**동시에 — 이 축은 균주를 못 가른다.** HslO·HisB·Tgt·PhnP 가 세 균주 모두
똑같이 잡는다. 균주 변별은 다른 축(mmseqs)이 한다.

## S4. 등급 규칙

**올릴 것 (그림 한 장 + 표)**

```
1. 예측 구조에서 NI 좌표를 찾는다
2. 2.6 Å 안의 원자를 모은다   ← 후보 단백질 사슬만. ChCODH2 는 제외
3. 잔기 단위로 중복 제거
4. 도너 종류로 등급
```

| 등급 | 조건 | 뜻 |
|---|---|---|
| **A** | Cys ≥ 4 | 티올레이트 4개 — **금속을 잡았다 놓는 운반형 자리** |
| **B** | Cys 3 / Cys2+His | 구조적 금속 자리 |
| **C** | Cys 1–2 / His ≥ 3 | 촉매 금속 자리 가능성 |
| **D** | 그 외 (산소 위주) | **표면 부착 의심** |

**왜 Cys 개수인가 (화학)**

HSAB — Ni(II) 는 **연한 금속**, Cys 티올레이트 S⁻ 는 **연한 염기**.
Asp/Glu 의 카복실산 O 는 **단단한 염기**로 Mg²⁺·Ca²⁺ 쪽이다.
**금속을 운반하는 단백질은 티올레이트를 쓴다** — HypA, CooC, 메탈로티오네인,
아연 손가락이 전부 그렇다.

**두 상수를 구분할 것**

| | 값 | 무엇 |
|---|---|---|
| `CUT_NI` | 3.5 Å | **Ni 이 어디엔가 놓였나** → **411 / 411 전부 통과.** 변별력 0 |
| `TIGHT` | **2.6 Å** | **배위로 세는 선** → 여기서 등급이 갈린다 |

> "Boltz 가 Ni 을 넣었다"는 아무 정보가 아니다. **다 넣는다.**
> 정보는 **어떻게 물었나**에 있다.

## S6. YeiR — 거리만 보면 안 되는 이유 (사례 하나)

**올릴 것**

```
YeiR (COG0523 금속 샤페론 GTPase)   앞선 후보 목록의 1번이었다

  2.6 Å 안의 도너 :  HIS209  하나뿐        (n_donor = 1)
  CYS65          :  2.69 Å 로 잘림         (Ni–S 는 2.2 Å 근처여야 한다)

  → grade D. "붙었다"로 세던 것이 실제로는 표면 접촉이었다
```

**말할 것**

> 계통 근거(COG0523, 금속 샤페론 과)는 강했다. 그런데 자리를 열어 보니
> 배위가 아니라 표면 접촉이었다. **계통으로 고른 후보를 기하가 내렸다.**

**예상 질문** — *"0.09 Å 차이로 내리는 게 맞나?"*
→ 맞다고 단정하지 말 것. 정직한 답: **`TIGHT` 를 3.0 으로 올리면 D 가 C 로
올라오기 시작한다.** 이 경계는 우리가 정한 것이고, YeiR 는 그 경계에 걸려 있다.
다만 `n_donor = 1` 은 경계와 무관하게 약하다 — 배위는 보통 4–6 좌표다.

**★ 그리고 이건 다시 볼 예정이다** — 다음 슬라이드(S7).

## S7. 단량체로 접은 것의 대가 — 다시 보는 중

**올릴 것 (그림)**

```
CooC1 의 Ni 자리 (3kji 실측)

   사슬 A  Cys112 ──┐
                    ├── Ni ── 두 단량체가 나눠 문다
   사슬 B  Cys112 ──┘
   (A114 / B114 도 같이)

   ZN A255 :  A114 2.23 · B114 2.24 · A112 2.27 · B112 2.28 Å
```

**말할 것**

> 우리는 후보를 **사슬 하나**로 접었다. 그러면 진짜 CooC 형 단백질도
> **자기 Cys 2개밖에 못 내놓는다.** 나머지 둘은 파트너 사슬에 있다.
> **grade C 가 곧 이량체 계면 자리의 신호일 수 있다.**

그리고 D 로 내린 **YeiR·HypB·UreG·CooC 는 전부 이량체**다. 단량체 예측이
이들에게 구조적으로 불리했을 수 있다.

**진행 중:** 해당하는 것들을 **동형이량체 + Ni** 로 다시 접는다.
양성대조군은 Ch CooC1 자신이다 — 그것이 `A-계면`으로 나오지 않으면 결과를 쓰지 않는다.


## S9. 후보

**올릴 것**

| # | 단백질 | 등급 | 다른 축 |
|---|---|---|---|
| **1** | **`QJZ12568.1`** hypothetical HO396_09830, 133 aa | **A** 2.23–2.40 Å | MG1655 프로테옴·게놈 **둘 다 부재** / **HypA 폴드** tm 0.66–0.68 |
| 2 | `QJZ13396.1` GspE, 497 aa | **A** 2.29–2.47 Å | MG1655 대비 fident 0.600 |
| — | `QJZ13803.1` HslO | A 2.18 Å | **세 균주 동일 — 변별력 없음** |

**1번에 대해 말할 것**

- 기능 미상 + **133 aa 소형** + Cys4 + **HypA 폴드**
- **HypA 는 [NiFe] 하이드로게나제 성숙의 Ni 삽입 인자**다. 우리가 찾는 것과 같은 일을 한다
- ChCODH2 의 C-cluster 도 [NiFe₄S₄] 다

**★ 방어해 둘 것 (반드시 나온다)**

> *"MG1655 에도 HypA 가 있지 않나?"*
> 있다. 주장은 **"MG1655 에 HypA 폴드가 없다"** 가 아니라
> **"이 특정 단백질이 없다"** 이다. 축2(폴드)와 축4(부재)는 다른 질문이고,
> 표에서 붙어 있어 헷갈리기 쉽다.

> *"근거가 네 개라고 하지 않았나?"*
> 셋이다. Cys4 재질의(folddisco) 히트는 **그 질의의 템플릿이 이 단백질 자신**이라
> 자기참조다. 근거에서 뺐다.
